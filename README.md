# Webstore – Creative E-Commerce Platform

## About the Project

**Webstore** is a full-stack e-commerce platform designed for creative businesses and individuals who want to showcase and sell unique, beautifully crafted products online.

The platform focuses on presenting creative ideas and products through visually appealing images, making it easy for customers to explore products and connect with a creativity-driven business.

The project includes both the **frontend and backend**, providing the complete functionality needed to operate an online creative store.

## Project Features

* Creative and visually appealing product presentation
* Online product showcasing through images
* Frontend interface for customers
* Backend functionality for managing the business
* Product and business-related backend services
* Full integration between the frontend and backend
* Organized project structure for easy development and maintenance

## Project Structure

The project is divided into two main parts:

* **`server/`** – Contains the backend of the application, including server configuration, routes, models, and other backend functionality.
* **`client/`** – Contains the frontend of the application and the user interface through which customers interact with the store.

## How to Run the Project

### 1. Start the Backend Server

Open a terminal in the project directory and run:

```bash
cd server
npm run dev
```

This will start the backend development server.

### 2. Start the Frontend

Open a **second terminal** and run:

```bash
cd client
npm run dev
```

This will start the frontend development server.

Both the backend and frontend need to be running simultaneously for the complete application to work properly.

## Technologies

The project uses modern web development technologies for both the frontend and backend. The specific dependencies and technologies can be found in the respective `package.json` files inside the `client` and `server` directories.

## Purpose

The goal of Webstore is to provide a complete online space where creativity meets business. It allows creative products and ideas to be presented beautifully while providing the technical foundation required to support an online store.
